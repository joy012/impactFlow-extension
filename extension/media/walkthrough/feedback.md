# Tell us what you think

ImpactFlow's value depends on its precision. Every false positive you flag tightens the heuristics.

## What to send

- **False positive?** A diff classified as `high` that was actually safe — paste the function + the diff label.
- **False negative?** A diff that should have been flagged but wasn't.
- **A feature request?** Behavior detectors, language ports, integrations — all welcome.

## How

- The **Feedback** tab in the side panel — encrypted submission over HTTPS.
- `ImpactFlow: Report a Bug` / `ImpactFlow: Request a Feature` from the command palette.
- Or open an issue directly on GitHub — link is in the feedback form.

## Privacy

- Submissions never contain your source code.
- Optionally attach the last 200 log lines (`Attach logs`) for crash reports.
- Optionally attach OS / VS Code / extension version (`Attach env`).
- Both are opt-in. Nothing leaves your machine without the consent line being checked.
